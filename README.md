# 📚 API-Livros

Este projeto consiste no desenvolvimento de uma **API de Livros**, criada como parte de uma atividade do **terceiro bimestre**.

A API tem como objetivo permitir o gerenciamento de informações relacionadas a livros, podendo futuramente incluir funcionalidades como cadastro, consulta, edição e exclusão de livros.

## 📋 Sobre a atividade

A atividade será desenvolvida durante **4 semanas**, sendo dividida em **4 etapas**.

Cada semana será destinada à realização de uma nova etapa do projeto, permitindo que a API seja construída de forma gradual.

### 🗓️ Etapas

* **Etapa 1:** Desenvolvimento inicial e configuração do projeto.
* **Etapa 2:** Continuação da implementação das funcionalidades da API.
* **Etapa 3:** Desenvolvimento e aprimoramento das funcionalidades.
* **Etapa 4:** Finalização, testes e conclusão do projeto.

## 🎯 Objetivo

O principal objetivo deste projeto é colocar em prática os conhecimentos adquiridos durante o terceiro bimestre, utilizando conceitos relacionados ao desenvolvimento de **APIs** e à manipulação de dados.

## 🚀 Projeto

**Nome:** API-Livros
**Tipo:** API
**Período:** 3º Bimestre
**Duração:** 4 semanas
**Total de etapas:** 4
