📚 API-Livros
📖 Sobre o projeto

Este projeto consiste no desenvolvimento de uma API para gerenciamento de livros, chamada API-Livros.

O projeto foi desenvolvido como parte de uma atividade do 3º bimestre e está dividido em 4 etapas, sendo realizada uma etapa por semana.

O objetivo é desenvolver o projeto gradualmente, começando pela criação da estrutura da API e conexão com o banco de dados, passando pela implementação das operações CRUD e finalizando com um frontend para consumir a API.

🎯 Objetivo

O principal objetivo deste projeto é colocar em prática conhecimentos relacionados ao desenvolvimento de APIs e aplicações web.

Durante o desenvolvimento serão trabalhados conceitos como:

Criação de APIs REST;
FastAPI;
Banco de dados MySQL;
Métodos HTTP;
Operações CRUD;
Backend;
Frontend;
Integração entre aplicações;
Consumo de API utilizando JavaScript.
🗓️ Etapas do projeto

O projeto está dividido em 4 etapas, sendo desenvolvida uma etapa por semana.

🔹 Etapa 1 - Fundação com FastAPI e MySQL

📁 Arquivo: 01-fundacao-fastapi-mysql.md

Nesta primeira etapa será realizada a preparação e estruturação inicial do projeto.

Os principais objetivos são:

Configurar o ambiente de desenvolvimento;
Criar a estrutura inicial da API;
Utilizar o framework FastAPI;
Configurar a conexão com o banco de dados MySQL;
Preparar a estrutura para armazenar os dados dos livros;
Realizar testes iniciais entre a API e o banco de dados.

Esta etapa será responsável por construir a base do projeto.

🔹 Etapa 2 - POST e GET

📁 Arquivo: 02-modelo-post-get.md

Na segunda etapa serão implementados métodos para cadastrar e consultar livros.

POST

O método POST será utilizado para adicionar novos livros ao sistema.

GET

O método GET será utilizado para consultar os livros cadastrados.

Algumas funcionalidades esperadas são:

Cadastrar livros;
Listar todos os livros;
Buscar informações de livros cadastrados.
🔹 Etapa 3 - PUT, DELETE e CRUD

📁 Arquivo: 03-put-delete-crud.md

Nesta etapa serão implementadas as operações restantes para completar o CRUD da API.

PUT

O método PUT será utilizado para atualizar informações de livros já cadastrados.

DELETE

O método DELETE será utilizado para remover livros do sistema.

Ao final desta etapa, a API deverá possuir um CRUD completo:

Operação	Método HTTP	Função
Create	POST	Criar um livro
Read	GET	Consultar livros
Update	PUT	Atualizar um livro
Delete	DELETE	Remover um livro
🔹 Etapa 4 - Frontend com HTML, CSS e JavaScript

📁 Arquivo: 04-frontend-html-css-js.md

Na última etapa será desenvolvido um frontend para interagir com a API.

Serão utilizadas as tecnologias:

HTML;
CSS;
JavaScript.

O frontend será responsável por consumir a API e permitir que o usuário interaja com o sistema visualmente.

Entre as funcionalidades esperadas estão:

Visualizar os livros cadastrados;
Adicionar novos livros;
Atualizar informações dos livros;
Excluir livros;
Consumir os endpoints da API utilizando JavaScript.

🚀 Resultado esperado

Ao final das quatro etapas, o projeto deverá possuir uma API completa para gerenciamento de livros, conectada a um banco de dados MySQL e integrada a um frontend.

O sistema deverá permitir:

📖 Cadastrar livros;
🔎 Consultar livros;
✏️ Atualizar informações;
🗑️ Excluir livros.
